# PROJECT_BRIEF — RandK Center

## Заказчик и продукт

**RandK Center** — сеть образовательных и языковых центров для детей, подростков и взрослых.

Города присутствия:

- Орехово-Зуево
- Павловский Посад
- Электросталь

Основной домен: `randkcenter.ru` (новый сайт заменяет действующий шаблонный сайт на платформе Megagroup).

## Задачи сайта

1. Современно представить сеть RandK и повысить доверие родителей и учеников.
2. Показать направления обучения и помочь посетителю выбрать программу.
3. Помочь выбрать ближайший филиал.
4. Получать заявки на пробное занятие и запросы на консультацию.
5. Направлять посетителей в Яндекс Карты.
6. Связать сайт с VK и MAX.
7. Подготовить основу для локального SEO в трёх городах.
8. Заменить устаревший сайт на основном домене без потери поискового трафика.

## Рамки проекта

Бюджет ориентировочно 50 000 ₽, поэтому в объём **не входят**:

- CRM и личный кабинет;
- полноценная CMS с админ-панелью;
- онлайн-оплата и расписание с бронированием мест;
- сложная backend-архитектура и база данных.

Вместо CMS используется **контент-слой в коде** (`src/content/*`): все редактируемые данные вынесены
в типизированные файлы, изменение текста/цен/адресов не требует правки компонентов.

## Технологический стек

| Слой      | Решение                                            |
| --------- | -------------------------------------------------- |
| Фреймворк | Next.js 15 (App Router)                            |
| UI        | React 19, TypeScript (strict)                      |
| Стили     | Tailwind CSS v4 + CSS-переменные (дизайн-токены)   |
| Анимации  | `motion` (Framer Motion v12), совместим с React 19 |
| Валидация | Zod v4 (одна схема на клиент и сервер)             |
| Заявки    | Route Handler `/api/lead` + адаптеры доставки      |
| Аналитика | Яндекс Метрика (подключается переменной окружения) |
| Качество  | ESLint 9, Prettier, `tsc --noEmit`                 |

## Ключевой принцип работы с данными

Бриф клиентом не заполнен. Поэтому в проекте действует жёсткое правило:

> **Сайт никогда не показывает неподтверждённый факт.**

Реализация:

- каждое неподтверждённое поле объявлено `nullable`, сущность имеет флаг `isConfirmed`;
- компоненты проверяют флаг и показывают нейтральную формулировку вместо выдумки;
- в JSON-LD не попадают неподтверждённые адреса, телефоны, рейтинги и отзывы;
- цифры (количество учеников, лет работы, проценты сдачи) на сайте отсутствуют.
