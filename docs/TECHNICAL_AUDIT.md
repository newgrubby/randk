## 4. Мобильный UX

Проверено на 360, 390, 430, 768, 1024, 1280, 1440 и 1920 px.

- **Горизонтальный скролл: 0 px на всех брейкпоинтах.**
- Шапка — 85 px, сжимается при скролле, первый экран не съедает.
- Нижняя навигация — 61 px плюс `env(safe-area-inset-bottom)`.
- Подвал получает такой же отступ, панель его не перекрывает.
- Модальные окна выше панели по `z-index` (100 против 80).

### Нижняя навигация

Было: три кнопки-действия в ряд, две из трёх дублировали контакт,
перемещаться по сайту было нельзя.

Стало: четыре постоянных пункта — **Главная · Языки · Центры · Связаться**.
У каждого иконка, подпись 12 px, зона нажатия 60 px, `aria-current="page"`
на активном разделе и точка-индикатор. «Связаться» стоит последним и
единственный залит акцентом: это конечное действие, а не раздел.

Прямой `tel:` из панели убран намеренно: сначала посетитель уточняет город, иначе звонок «куда-нибудь»
чаще промах, чем помощь. Кнопка открывает контактное окно с выбором города.

### Контактный сценарий

Открыть «Связаться» → город уже выбран и запоминается → «Позвонить».
Два действия. Если офисов в городе несколько, добавляется выбор офиса; при
одном офисе селектор не показывается вовсе, выводится адрес.

На мобильных окно ведёт себя как bottom sheet: прижато к низу, скруглено
только сверху, есть полоска-«ручка», `safe-area` снизу, `overscroll-contain`.
Закрытие по Escape и по клику на подложку, ловушка фокуса, блокировка скролла,
возврат фокуса на кнопку-инициатор.

### Прочее

- `-webkit-tap-highlight-color: transparent` — нет серой вспышки при тапе.
- `overscroll-behavior-y: none` — панель не отрывается от края при оттяжке.
- Минимум в интерфейсе — 12 px (подписи навигации), вторичный текст 13 px,
  основной 16 px и выше.

## 5. Доступность

Lighthouse, mobile и desktop:

| Страница                    | A11y | Best Practices | SEO |
| --------------------------- | ---- | -------------- | --- |
| `/`                         | 100  | 100            | 100 |
| `/languages/`               | 96   | 100            | 100 |
| `/centers/pavlovsky-posad/` | 100  | 100            | 100 |
| `/contacts/`                | 100  | 100            | 100 |

Единственное замечание — контраст крупного декоративного кода языка
(`text-accent/25`) на карточках `/languages/`. Элемент помечен `aria-hidden`,
скринридером не читается, это часть утверждённого оформления. 96 выше целевых
90, поэтому оформление не тронуто.

Исправлено и проверено: доступное имя логотипа, зоны нажатия, `aria-current`
в обеих навигациях, `aria-expanded` и `aria-controls` у мобильного меню,
`aria-pressed` у выбора города и офиса, ловушка фокуса в модальном окне,
skip-link, иерархия заголовков, alt у всех изображений.

## 6. Производительность

Замеры на production-сборке, локальный сервер, без throttling.

| Метрика | Было        | Стало     |
| ------- | ----------- | --------- |
| FCP     | 200 мс      | 96 мс     |
| **LCP** | **1476 мс** | **96 мс** |
| CLS     | 0.00        | 0.00      |

Причина: изображение первого экрана — самый крупный элемент страницы, то есть
LCP-кандидат. Оно оборачивалось в `motion.div` с появлением `opacity: 0 → 1`
и `scale: 1.04 → 1` длиной 1.1 с. Файл загружался за 6 мс, но Chrome не
засчитывает отрисовку, пока элемент анимируется, — метрика фиксировалась на
конце анимации. Анимация с изображения снята.

Анимации появления текста первого экрана сохранены: они дают редакционный вход
и на LCP больше не влияют, потому что изображение крупнее любого текста.

Прочее: 18 клиентских компонентов, все с реальной интерактивностью. Шрифты
грузятся за 69 мс, CSS блокирует рендер на 8 мс. Яндекс Метрика подключается
только при заданном ID.

## 7. Краевые случаи

| Случай                          | Поведение                                                                                                               |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| JavaScript выключен             | Первый экран, секции, телефоны и ссылки работают. `<noscript>` покрывает все 35 анимированных элементов на 26 страницах |
| `prefers-reduced-motion`        | Анимации отключаются через `useReducedMotion`                                                                           |
| `maxUrl = null`                 | Кнопка MAX не рендерится нигде                                                                                          |
| `mapUrl` не задан               | «Построить маршрут» только при наличии URL или координат                                                                |
| Один офис в городе              | Селектор скрыт, выводится адрес                                                                                         |
| Несколько офисов                | Селектор с адресом и уточнением                                                                                         |
| Скрытый язык или программа      | Не попадают в меню, подвал, каталог и sitemap                                                                           |
| Прямой заход по URL, обновление | Работает: статический экспорт с `trailingSlash`                                                                         |
| 404                             | Отдаётся 404, не редирект                                                                                               |
| Старые адреса                   | 40 правил, синхронны в `.htaccess` и `vercel.json`                                                                      |
