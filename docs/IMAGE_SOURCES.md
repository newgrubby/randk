# IMAGE_SOURCES — происхождение изображений

## Статус: ВСЕ ИЗОБРАЖЕНИЯ ВРЕМЕННЫЕ

На момент разработки клиент не передал фотографии. Все изображения в `public/images/`
**сгенерированы для этого проекта** и подлежат замене.

## Что используется сейчас

| Файл                         | Размер      | Где применяется                                    |
| ---------------------------- | ----------- | -------------------------------------------------- |
| `images/hero.svg`            | 1200×900    | первый экран главной                               |
| `images/about.svg`           | 1000×750    | страница «О центре»                                |
| `images/programs/*.svg`      | 800×600     | 7 карточек и страниц направлений                   |
| `images/ages/*.svg`          | 600×720     | 4 карточки блока «Программы по возрасту»           |
| `images/branches/*.svg`      | 900×640     | 3 карточки и страницы центров                      |
| `og.png`                     | 1200×630    | превью при отправке ссылки в мессенджеры и соцсети |
| `icon.svg`, `apple-icon.png` | 64 / 180 px | favicon и иконка на домашнем экране                |

## Чем они являются

Абстрактные редакционные композиции в фирменной палитре: слоистые арки, тонкая линейная сетка
(«строки тетради») и один красный акцент.

**Что на них НЕ изображено:** люди, дети, преподаватели, интерьеры, логотипы, текст.

### Почему не стоковые фотографии

1. Фото «улыбающихся детей за партой» создаёт ложное впечатление о конкретном центре — посетитель
   считает это фотографией реального класса RandK.
2. Стоковые снимки мгновенно опознаются и удешевляют сайт — ровно то, чего проект должен избежать.
3. Лицензирование стоковых фото с детьми — отдельный юридический вопрос, который нельзя решать за клиента.

Абстракция честнее: она держит композицию и ритм страницы, не притворяясь реальностью.

## Как они сделаны

Генератор: `scripts/generate-placeholders.mjs`

```bash
node scripts/generate-placeholders.mjs
```

Особенности:

- **детерминированный** — у каждого файла свой seed, композиции стабильны между сборками и не «прыгают» в git;
- **лёгкий** — SVG весит 1–2 kB против сотен килобайт у фото;
- палитра берётся из тех же значений, что и дизайн-токены.

Лицензия: код генератора и его вывод созданы в рамках проекта, принадлежат заказчику,
сторонних материалов не содержат.

## Как заменить на реальные фотографии

**Шаг 1.** Подготовить файлы:

| Что                     | Формат           | Минимальный размер     |
| ----------------------- | ---------------- | ---------------------- |
| Первый экран            | `.jpg` / `.webp` | 2000 px по ширине      |
| Фото центров            | `.jpg` / `.webp` | 1600 px по ширине      |
| Карточки программ       | `.jpg` / `.webp` | 1200 px по ширине      |
| Портреты преподавателей | `.jpg` / `.webp` | 800×1000, вертикальные |

**Шаг 2.** Положить в `public/images/` и обновить путь в контенте:

```ts
// src/content/programs.ts
image: {
  src: '/images/programs/english.jpg',   // ← новый путь
  alt: 'Занятие по английскому языку в центре RandK',  // ← описательный alt
  isClientProvided: true,                // ← отметить как реальное фото
},
```

`next/image` сам сделает WebP/AVIF, размеры под устройство и ленивую загрузку — дополнительная
оптимизация не нужна.

**Шаг 3.** Проверить `alt`: он должен описывать, что на фото, а не повторять название программы.

**Шаг 4.** Заменить `og.png` — это превью ссылки в мессенджерах, оно сильно влияет на кликабельность.

## Требования к фотографиям

✅ **Нужно**

- реальные центры, классы, ученики и преподаватели;
- естественное освещение, тёплая гамма (сочетается с молочным фоном);
- горизонтальные кадры для секций, вертикальные для портретов;
- разные возрастные группы: дошкольники, школьники, подростки, взрослые.

❌ **Нельзя**

- логотипы и материалы других школ в кадре;
- фото детей без письменного согласия родителей;
- изображения ниже 1200 px по ширине — они будут «мылить» на ретине;
- скриншоты и коллажи;
- чужие фото из интернета без лицензии.

## Логотип

Векторного логотипа нет. Знак собран типографикой в `src/components/layout/Logo.tsx`
(Playfair Display «RandK» + разрядка «CENTER»).

📌 **Нужен от клиента:** оригинал в SVG, AI или EPS. Замена затрагивает один файл.
Растровое изображение из шапки старого сайта не подходит — низкое разрешение.
