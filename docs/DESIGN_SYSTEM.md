# DESIGN_SYSTEM — RandK Center

Источник истины по токенам: `src/app/globals.css` (блок `@theme`).
Изменение переменной там меняет весь сайт — в компонентах цвета и размеры не хардкодятся.

## Характер

**Premium editorial.** Сайт должен читаться как разворот качественного журнала об образовании:
крупная типографика, воздух, спокойная тёплая палитра, один красный акцент.

Что мы **не** делаем:

- инфантильных школьных клише (радуги, карандаши, мультяшные дети);
- кислотных градиентов и разноцветных блоков;
- вида SaaS-панели (плотные карточки, таблицы, обилие бейджей);
- анимаций ради анимаций.

Эталон концепции: `references/randk-selected-concept.png`. Макет использован как ориентир по духу,
композиции и палитре, а не копировался механически.

## Цвет

| Токен                   | Значение  | Назначение                               |
| ----------------------- | --------- | ---------------------------------------- |
| `--color-background`    | `#f7f4ef` | тёплый молочный фон страницы             |
| `--color-surface`       | `#ffffff` | карточки, формы, светлые секции          |
| `--color-surface-muted` | `#efe9e0` | бежевые секции, чередование ритма        |
| `--color-surface-deep`  | `#241f1d` | тёмная секция «Результаты» и подвал      |
| `--color-text`          | `#1f1c1a` | графитовый основной текст                |
| `--color-muted`         | `#6d6660` | вторичный текст, подписи                 |
| `--color-accent`        | `#ad1f2b` | глубокий красный — главный акцент бренда |
| `--color-accent-dark`   | `#7d1119` | hover кнопок, тёмный акцент              |
| `--color-accent-soft`   | `#f5e7e6` | подложка выбранных состояний и ошибок    |
| `--color-border`        | `#e3dcd2` | спокойные границы                        |
| `--color-border-strong` | `#cfc5b8` | границы кнопок и активных элементов      |

**Правило акцента:** красный обозначает действие или бренд. Он не используется для декора.
На экране обычно одна главная красная кнопка.

**Контраст:** `--color-text` на `--color-background` ≈ 14:1, `--color-muted` на фоне ≈ 5.3:1,
белый на `--color-accent` ≈ 7.4:1 — все выше порога WCAG AA.

## Типографика

Пара шрифтов (оба с кириллицей, лицензия OFL, подключены через `next/font` — самохостинг, без запросов к Google):

- **Playfair Display** (`--font-serif`) — заголовки. Высокий контраст штриха даёт «дорогое» редакционное звучание. Курсив используется для акцентной строки в заголовках.
- **Inter** (`--font-sans`) — интерфейс и основной текст. Нейтральный, отлично читается в мелком кегле.

### Шкала

Все размеры на `clamp()` — плавная адаптация без скачков на брейкпоинтах.

| Токен          | Диапазон              | Применение               |
| -------------- | --------------------- | ------------------------ |
| `text-display` | 40 → 80 px            | заголовок первого экрана |
| `text-h1`      | 34 → 60 px            | H1 внутренних страниц    |
| `text-h2`      | 28 → 46 px            | заголовки секций         |
| `text-h3`      | 20 → 26 px            | заголовки карточек       |
| `text-lead`    | 17 → 20 px            | лид-абзацы               |
| `text-eyebrow` | 12 px, трекинг 0.16em | надзаголовки капсом      |

**Правила:**

- минимальный кегль основного текста — 14 px (`text-sm`), мельче только служебные подписи;
- заголовки — `text-wrap: balance`, абзацы — `text-wrap: pretty` (нет висячих строк);
- на странице ровно один `<h1>`.

## Сетка и ритм

- `.container-page` — максимум **1440 px**, поля: 20 px (моб.) → 40 px (планшет) → 64 px (десктоп).
- `.container-prose` — 736 px для длинных текстов (юридические страницы).
- Основная сетка — 12 колонок (`lg:grid-cols-12`), контролируемая асимметрия: 5/7 и 7/5 вместо симметричных половин.
- Вертикальный ритм секций: `tight` (56/80 px) → `default` (80/128 px) → `loose` (96/176 px).
- Фоны секций **чередуются** (`default → surface → muted → deep`), чтобы страница дышала и не читалась как один длинный список.

## Анимация

Единый язык движения: **сдвиг вверх 16–28 px + проявление**, кривая `cubic-bezier(0.25, 1, 0.5, 1)`, длительность 0.35–0.85 s.

| Место          | Поведение                                                            |
| -------------- | -------------------------------------------------------------------- |
| Первый экран   | каскад: надзаголовок → H1 → лид → кнопки → преимущества (0.05 s шаг) |
| Карточки       | stagger 0.07–0.08 s внутри ряда                                      |
| Изображения    | масштаб 1.05 при наведении, 0.7 s                                    |
| Ссылки         | подчёркивание раскрывается слева направо                             |
| Кнопки         | сдвиг на 1 px при нажатии, стрелка уезжает вправо                    |
| Модальное окно | подложка fade + панель со сдвигом снизу                              |
| Квиз           | шаг въезжает справа, прогресс-бар анимирует ширину                   |

**Ограничения:** нет постоянного движения, нет параллакса, нет 3D, нет горизонтального скролла.

### prefers-reduced-motion

Поддержан на двух уровнях:

1. CSS — все анимации и переходы сокращаются до 0.001 ms, `scroll-behavior: auto`.
2. JS — `useReducedMotion()` в `Reveal`, `Modal`, `Quiz`, `MobileMenu`, `Accordion`: движение отключается, **но контент остаётся видимым** (не остаётся `opacity: 0`).

## Доступность

- видимый фокус: `:focus-visible` — красная обводка 2 px с отступом 3 px;
- ссылка «Перейти к содержимому» первым элементом в DOM;
- все интерактивные элементы достигаются с клавиатуры;
- у всех полей форм связанный `<label for>`;
- ошибки форм — `role="alert"`, состояние отправки — `aria-live="polite"`;
- у иконок `aria-hidden`, у иконочных кнопок `aria-label`;
- цель нажатия минимум 44 px по высоте.
