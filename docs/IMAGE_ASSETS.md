## Три типа временных изображений

### 1. Editorial-композиции

Слоистые арки, тонкая линейная сетка («строки тетради») и один красный акцент.
Используются для hero, направлений и возрастных ступеней.

**Что на них НЕ изображено:** люди, дети, интерьеры, логотипы.

### 2. Карточки языков

То же плюс крупный код языка (`EN`, `DE`, `中文`) типографским акцентом.
Флаги намеренно не используются: флаг обозначает страну, а не язык — испанский
не равен Испании, английский не равен Великобритании.

### 3. Карточки офисов

Фирменная композиция с названием города, адресом, абстрактными линиями карты
и меткой-пином.

⚠️ **Фасады и интерьеры не рисуются намеренно.** Сгенерированное здание,
выданное за реальный офис RandK, — прямая дезинформация: посетитель поедет
искать то, чего не существует.

## Требования к фотографиям

✅ **Нужно**

- реальные помещения, классы и занятия;
- естественное тёплое освещение — сочетается с молочным фоном сайта;
- премиальная редакционная подача, а не отчётная съёмка;
- разные возрастные группы.

❌ **Нельзя**

- логотипы и материалы других школ в кадре;
- водяные знаки;
- фото детей без письменного согласия родителей;
- изображения ниже 1200 px по ширине — они «мылят» на ретине;
- текст внутри фотографии;
- чрезмерно постановочные эмоции и очевидный фотосток.

## Как заменить изображение

1. Положить файл в `public/images/client/` (или в тематическую папку).
2. Обновить путь в контенте:

```ts
// src/content/languages.ts, programs.ts, centers.ts
image: {
  src: '/images/client/english-lesson.jpg',
  alt: 'Занятие по английскому языку в центре в Орехово-Зуеве',
  width: 1200,
  height: 800,
  isClientProvided: true,   // ← отметить как реальное фото
}
```

3. Проверить `alt`: он описывает, что на фото, а не повторяет название страницы.

## Оптимизация

**В режиме standalone** `next/image` сам делает WebP/AVIF, адаптивные размеры
и ленивую загрузку — достаточно положить исходник.

**В режиме статического экспорта** оптимизатор недоступен, поэтому изображения
нужно подготовить заранее:

```bash
npx sharp-cli --input photo.jpg --output photo.webp resize 1600 --format webp
```

Ориентиры по весу: hero — до 250 КБ, карточки — до 120 КБ.

Настройки, уже действующие на сайте:

- `priority` только на hero и первом изображении внутренних страниц;
- всё остальное грузится лениво;
- у каждого изображения заданы пропорции контейнера — layout shift отсутствует.

## Промпты для повторной генерации

Если временные изображения нужно пересоздать в другом стиле, генератор
принимает параметры в `scripts/generate-placeholders.mjs`. Для внешних
инструментов генерации подойдут такие описания:

- **Hero:** «светлый образовательный интерьер, тёплый естественный свет, мягкие
  бежевые и молочные тона, минимализм, редакционная фотография, без людей крупным планом»;
- **Возрастные ступени:** «занятие в светлом классе, естественный свет, тёплая
  палитра, спокойная атмосфера, документальная подача»;
- **Языки:** «абстрактная редакционная композиция, тёплые бежевые тона, один
  глубокий красный акцент, геометрия, без текста».

⚠️ Сгенерированные изображения людей нельзя выдавать за сотрудников или
учеников RandK — только как очевидно абстрактную иллюстрацию.

⚠️ Портреты сотрудников не запрашиваются и не публикуются: Информация о преподавателях на сайте не публикуется по решению клиента.
